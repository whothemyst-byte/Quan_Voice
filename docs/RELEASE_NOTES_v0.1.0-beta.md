## Quan Voice `v0.1.0-beta`

First public beta release of Quan Voice for Windows.

### What’s included
- Desktop app build with floating mic workflow
- Dashboard and settings screens
- Model download/setup flow
- Injection/hotkey related backend wiring (beta quality)

### Install (Windows x64)
1. Download `Quan Voice_0.1.0_x64-setup.exe` from the release assets.
2. Run the installer.
3. If Windows SmartScreen appears, click **More info** -> **Run anyway**.
4. Launch **Quan Voice** from Start Menu or desktop shortcut.
5. On first launch, allow microphone permission if prompted.

### Notes
- This is a beta release; rough edges are expected.
- If your antivirus flags a newly built unsigned app, verify you downloaded from this official release page.

### Need help
If something breaks, open an issue with:
- Windows version
