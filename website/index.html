Install in under 3 minutes

  1. Download Quan Voice_0.1.0_x64-setup.exe.
  2. Run installer and continue through SmartScreen if prompted.
  3. Launch Quan Voice and select your microphone in Settings.
  4. Activate and start dictating with your push-to-talk key.
