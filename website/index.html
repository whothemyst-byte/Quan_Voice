Voice typing that stays local and fast.

Quan Voice brings push-to-talk transcription to your desktop with an interface designed for focus. Download the latest beta build for Windows x64.

Download .exe View Release

If direct download is unavailable, open the release page and use the latest installer asset.

Install in 5 steps

  1. Download Quan Voice_0.1.0_x64-setup.exe.
  2. Run the installer.
  3. If SmartScreen appears, click More info then Run anyway.
  4. Open Quan Voice from Start Menu.
  5. Allow microphone access on first launch.

Why Quan Voice

  • Offline-oriented transcription workflow
  • Minimal dashboard and floating mic widget
  • Configurable push-to-talk hotkey
  • Private-by-design desktop experience
